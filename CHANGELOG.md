# CHANGELOG

## 1.0.0 — 2026-10-18
- Se añadió el dataset público WDBC en versión inicial y preparada.
- Se documentó el diccionario de datos y los supuestos de limpieza.
- Se implementó regresión logística y Random Forest con búsqueda de hiperparámetros por GridSearchCV y validación cruzada estratificada de cinco folds.
- Se incorporó seguimiento con MLflow para parámetros, métricas, modelos y artefactos.
- Se añadieron métricas, predicciones, curvas ROC, comparación de métricas y contraste estadístico exploratorio.
- Se documentaron limitaciones, especialmente que el prototipo no es un dispositivo de diagnóstico.
