# Fuentes

- `entrena.ipynb`: notebook para Google Colab; instala dependencias, carga el dataset público, prepara, entrena dos modelos, ajusta hiperparámetros y registra experimentos MLflow.
- `datos_prep.py`: funciones de adquisición y limpieza.
- `train.py`: entrenamiento reproducible por terminal.

Ejecuta desde la raíz: `python fuentes/train.py`.
